# Architecture Decision Records

Shared SightPress decisions are recorded in the `core` repo, in `docs/adr/`.

This folder is for decisions that only affect this repo. Use the same format and rules as `core`:
file names `NNNN-short-title.md`, start from core's `0000-template.md`, statuses *Proposed*, *Accepted*,
*Superseded by …* or *Rejected*. Never edit an accepted decision; supersede it with a new ADR.
